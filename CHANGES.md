# What's new

Each "## version" section becomes the notes on that version's GitHub release.

## 1.1.4
First public release.

- Pick colors from any number of images, with a zoom magnifier that shows the exact pixel.
- Build a color sheet: rainbow sort, average color, drag to reorder, undo and redo.
- Give a sheet a title, date and description.
- Save sheets as palettes and open them again later.
- Copy colors as Hex, CSS or RGB. OneNote, Word and Google Docs get a colored block next to
  each code; Notepad and Discord get plain codes.
- Copy the whole sheet as a picture.
- Updates itself from this page (you can switch that off).
